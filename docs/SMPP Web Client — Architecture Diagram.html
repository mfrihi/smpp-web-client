SMPP v3.4 Web Client — Architecture

agent.onldigital.com/smpp-client/ · 6,541 LOC · v4.0

Client Tier

  • Single-page app with 11 panels
  • Cyberpunk glass-morphism theme
  • Socket.IO real-time communication
  • Character counter + split preview
  • Auto-encoding detection (GSM-7/UCS-2)
  • RTL support for Arabic interface

Backend Tier

  • Node.js + Express + Socket.IO
  • SmppManager: session, windowing, DLR, split
  • WebSocketHandler: 22+ event routing
  • ThroughputManager: rate-controlled burst (1-100/s)
  • Auto-pause after 10 consecutive throttles
  • No retry budget — silent re-queue on throttle

SMSC & Deployment

  • SMPP v3.4 via TCP (port 2775)
  • Built-in SMSC simulator for testing
  • Deployed: agent.onldigital.com/smpp-client/
  • Apache reverse proxy with WebSocket upgrade
  • Cache busting via ?v= query parameter
  • PM2 process manager / Systemd service
